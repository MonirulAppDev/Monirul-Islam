# Monirul Islam - Flutter Developer Portfolio

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by the development server.

## Where to update content

- `data/portfolio.ts`: projects, GitHub/Play Store/App Store URLs, skills, testimonials, experience, contact links, CV link and Calendly link.
- `components/ProjectCard.tsx`: project-card layout and icon buttons.
- `components/Projects.tsx`: project listing and case-study modal.
- `components/HeaderHero.tsx`: navigation, hero and recruiter toolkit.
- `components/Credentials.tsx`: testimonials, availability, expertise and experience.
- `components/Contact.tsx`: contact section and footer.
- `app/globals.css`: design system, responsive layout and animations.
- `app/layout.tsx`: SEO and social-sharing metadata.
- `public/`: CV, social preview and static assets.

## Replace demo content

Search for `Demo` or `Replace later`. Replace the placeholder store URLs, testimonials, notice period and Calendly management URL with public production links.

## Production build

```bash
npm run build
```
